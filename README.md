## Инструкция по запуску проекта

1. **Создайте папку**, в которую будет помещён проект.
2. **Перейдите в эту папку** через Git Bash.
3. **Инициализируйте git-репозиторий** командой: git init
4. **Склонируйте файлы из репозитория** командой:git clone git@github.com:Alexander-Risovsky/Web-service-for-cash-flow-management.git
5. **Откройте папку с проектом** через вашу IDE (например, VS Code).
6. **Перейдите в папку** `/Web-service-for-cash/DDS`.
7. **Создайте виртуальное окружение** командой: python -m venv venv
8.  **Активируйте виртуальное окружение** командой: source venv/Scripts/activate
Для Windows PowerShell используйте:  `venv\Scripts\Activate.ps1`
9. **Установите все зависимости** командой: pip install -r requirements.txt

10. **Создайте таблицы в базе данных** командой: python manage.py migrate
11. **Запустите локальный сервер** командой: python manage.py runserver

# DDS — Веб-сервис для управления движением денежных средств

## Описание

DDS — это Django-приложение для учёта и управления движением денежных средств. Сервис позволяет вести записи о расходах и доходах, а также управлять справочниками (категории, подкатегории, типы, статусы) для гибкой фильтрации и структурирования данных.

---

## Структура проекта

- **DDS/** — основной проект Django (настройки, маршрутизация).
- **main/** — приложение для главной страницы и фильтрации записей.
- **records/** — приложение для работы с финансовыми записями (CRUD, фильтрация, AJAX для динамических форм).
- **guides/** — приложение для управления справочниками: категории, подкатегории, типы, статусы.
- **static_dev/** — директория для статических файлов (CSS, JS).
- **templates/** — шаблоны для всех страниц.

---

## Основной функционал

### 1. Учёт записей (приложение `records`)
- Добавление, редактирование и удаление записей о движении средств.
- Каждая запись содержит: дату, статус, тип, категорию, подкатегорию, сумму, комментарий.
- Динамическая подгрузка категорий и подкатегорий по выбранному типу/категории (AJAX).

### 2. Фильтрация и просмотр (приложение `main`)
- Главная страница с фильтрами по дате, статусу, типу, категории и подкатегории.
- Таблица с результатами фильтрации.

### 3. Управление справочниками (приложение `guides`)
- CRUD для категорий, подкатегорий, типов и статусов.
- Удобная навигация между справочниками.
- Возможность привязывать подкатегории к категориям, а категории — к типам.
